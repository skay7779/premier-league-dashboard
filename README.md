## What's inside

- `prep_data.py`: Python (pandas) script that cleans five seasons of match data and reshapes it into one row per team per match and one row per team per season, adding points, rolling 5-game form, shot conversion and home/away splits.
- Three Tableau dashboards: league overview and points race; chance creation vs finishing; team deep dive.
- `screenshots/`: images of each dashboard.
